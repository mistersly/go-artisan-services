Couleurs

Palette monochrome : un seul accent — le noir — réservé aux actions primaires. Les couleurs sémantiques n'apparaissent que sur les pastilles de statut et les messages d'erreur. Toute couleur dérivée passe par color-mix() à partir d'un token.

04

Boutons

Deux variantes seulement. Le bouton primaire est noir et réservé à l'action décisive de l'écran ; le secondaire est neutre. Survol, appui, focus et désactivé sont définis par couple fond / texte.

Variantes .btn-primary · .btn-secondary
Le survol du primaire lighten le fond vers --accent-hover (mélange 10 % de blanc) — le texte blanc reste inchangé, le contraste ne baisse jamais. Cette page est un catalogue : elle présente la variante primaire plusieurs fois, alors qu'un écran produit n'admet qu'un seul appel primaire.
États hover · focus-visible · active · busy · disabled
Survol (focus simulé) Chargement Désactivé Plein largeur
Anneau de focus : 0 0 0 2px var(--bg), 0 0 0 4px var(--accent) — un halo de canvas puis l'anneau d'accent.

06

Badges & statuts

Les pastilles qualifient un état, jamais une action. Trois statuts métier — actif, en attente, suspendu — plus une variante neutre et une variante pleine pour les.tags prioritaires.

Variantes .badge[data-status] · .badge[data-variant]
Neutre Prioritaire Actif En attente Suspendu
Texte et bordure sont dérivés du token sémantique par color-mix(), le fond reste à 95 % de blanc. Le point de couleur est le seul signal chromatique du statut.
Usage règle

Un badge ne porte jamais plus de trois mots et n'est pas cliquable : c'est la ligne entière qui reçoit l'action. Les statuts se lisent dans un tableau, jamais dans un titre.

10

Règles d'usage

Six règles non négociables. Elles arbitrent les cas litigieux : en cas de doute, la règle la plus sobre l'emporte.

Palette uniquement

  • 01 Aucune couleur en dur hors du bloc :root ; toute nuance passe par color-mix().
  • 02 Le noir est le seul accent. Bleu, violet, dégradés et ombres colorées sont exclus.

Typographie

  • 01 Geist pour l'affichage et le texte, Fira Code pour les données techniques.
  • 02 Graisses 400 / 500 / 600 seulement ; jamais d'ombre portée sur un texte.

Posture de mise en page

  • 01 Grille de 4 px, rayons 6 / 8 / 12 px, deux couches d'élévation au maximum.
  • 02 Aucune illustration décorative, aucun dégradé, aucun halo d'accent.

Un seul appel primaire

  • 01 Une action primaire par écran : celle qui conclut le parcours en cours.
  • 02 Les autres actions restent secondaires, jamais pleines.

Contraste des états

  • 01 Le survol ne baisse jamais le contraste entre le texte et son fond.
  • 02 Focus visible sur chaque contrôle : anneau de 2 px canvas puis 2 px accent.

Pas de vernis

  • 01 Pas d'emoji, pas d'image générée, pas de micro-animation décorative.
  • 02 Le contenu réel remplace toute phrase d'appoint et tout remplissage.
